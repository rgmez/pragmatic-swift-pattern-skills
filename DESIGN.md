# Design System

## Mode

Read. Readers should understand the position, select the right skill, and reach installation or evidence within seconds.

## Visual world

Use RG's premium technical-editorial system: matte black or charcoal grounds, white primary type, muted gray secondary copy, RG red, and warm orange-red functional accents. Industrial evidence-gate imagery may frame the repository, but the reading column stays calm and conventional.

## Typography and hierarchy

- GitHub's native reading typography owns body copy and headings.
- Use one H1, short opening promise, and a visible position statement before detailed installation.
- Use monospace only for commands, paths, identifiers, and data.
- Keep each prose paragraph and list item on one logical Markdown line.

## README structure

- Root: hero image, position, four-skill pipeline, skill selector, living-sync explanation, installation, validation, and repository map.
- Skill: clear promise, position, use/do-not-use boundary, workflow Mermaid, inputs/outputs, examples, installation, and source-of-truth note.
- Skill icon: one semantic glyph for the responsibility boundary, shown once near the title and bundled for host UI metadata.
- Secondary maintenance details belong in `<details>` blocks or linked docs.

## Visual tokens

| Token | Value | Use |
| --- | --- | --- |
| Canvas | `#0B0B0C` | Hero and social-preview background |
| Surface | `#161618` | Industrial scene and dark panels |
| Primary | `#FFFFFF` | Titles and primary claims |
| Secondary | `#A7A7A7` | Supporting explanation |
| RG red | `#C92A2A` | Brand mark and decisive emphasis |
| Warm orange | `#F4512C` | Evidence gates, links, and active accents |
| Icon surface | `#111214` | Skill icon background |

## Signature

One direct rail passes through an evidence gate before branching into pattern work. This metaphor belongs in the hero and sync diagrams, not repeated around every section.

## Accessibility

- Every raster has descriptive alt text.
- Every SVG icon has a title, accessible description, and non-color semantic shape.
- Mermaid diagrams have a prose explanation.
- Tables remain compact and carry exact comparisons only.
- Do not rely on color to distinguish use from refusal.
- Avoid decorative emoji as the navigation system.
