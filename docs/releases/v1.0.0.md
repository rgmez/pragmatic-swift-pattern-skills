# v1.0.0 — Evidence Before Abstraction

Pragmatic Swift Pattern Skills 1.0.0 packages one position: design patterns are valuable when verified pressure moves responsibility to a better owner, and direct Swift is the correct result when no such pressure exists.

## Included skills

| Skill | Decision boundary |
| --- | --- |
| `choose-swift-design-pattern` | Decide whether one current Swift requirement has earned one GoF pattern. |
| `implement-swift-design-pattern` | Encode one earned boundary with the smallest useful Swift representation and behavioral tests. |
| `teach-swift-design-pattern` | Turn verified code and tests into a standalone decision-first guide. |
| `audit-swift-pattern-catalogue` | Review a multi-pattern catalogue for evidence, classification, overengineering, and release readiness. |

## Living evidence

The repository synchronizes an explicit allowlist from `rgmez/Design-Patterns-in-Swift`. It tracks the latest commit that touched the allowlisted evidence, so unrelated catalogue commits create no generated churn.

Evidence changes open a reviewable pull request. Automation never edits human-authored `SKILL.md` files, merges its own pull request, or publishes a release.

## Verified distribution

- Agent Skills frontmatter and package links pass the repository validator, Codex `quick_validate.py`, and the Agent Skills reference validator.
- Eight versioned evaluation cases cover one normal and one safety-stop scenario per skill.
- `skills@1.8.1` discovers and installs complete package copies for Codex, Claude Code, Cursor, and GitHub Copilot.
- CI compares installed package contents with their canonical source directories.

## Install

```sh
npx skills add rgmez/pragmatic-swift-pattern-skills --skill '*'
```

Select hosts explicitly with `--agent codex`, `--agent claude-code`, `--agent cursor`, or `--agent github-copilot`.

## Known limits

Installation validation proves packaging and destination integrity, not identical reasoning across hosts. Run the versioned cases in `evals/cases.json` against the intended host when behavioral equivalence matters.
